# Técnico em Desenvolvimento de Sistemas - SENAI

Este repositório contém o registro da minha jornada acadêmica e prática no curso de **Técnico em Desenvolvimento de Sistemas** realizado no **SENAI**. Aqui, documento o progresso das minhas competências em programação, infraestrutura e análise de software.

---

## 📌 Sobre o Repositório
O objetivo deste espaço é centralizar todas as atividades, projetos e estudos realizados durante as unidades curriculares do curso. Ele serve como um portfólio técnico para demonstrar a aplicação prática dos conceitos aprendidos em sala de aula e nos laboratórios.

---

## 🛠️ Conteúdo e Unidades Curriculares

### 1. Lógica de Programação e Algoritmos
Base fundamental para o desenvolvimento de software, focada na resolução de problemas e estruturação de pensamento computacional.
* **Portugol:** Primeiros passos com lógica e algoritmos através do Portugol Studio.
* **C++:** Transição para linguagem compilada, trabalhando com tipos de dados, manipulação de variáveis e performance.
* **Python:** Desenvolvimento de scripts, automações e exercícios de lógica com sintaxe moderna e simplificada.
* **Conceitos:** Estruturas condicionais, laços de repetição, vetores, matrizes e modularização (funções).

### 2. Redes com IoT (Internet das Coisas)
Estudo da comunicação entre dispositivos e a integração do mundo físico com o digital.
* **Foco:** Protocolos de rede, endereçamento IP, configuração de roteadores e integração de sensores com microcontroladores utilizando lógica em **C++** ou **Python**.

### 3. Sistemas Operacionais
Exploração do funcionamento interno do computador e gerenciamento de recursos.
* **Atividades:** Instalação e configuração de ambientes Windows e Linux, manipulação de terminal (Bash), gerenciamento de processos, usuários e permissões de arquivos.

### 4. Levantamento de Requisitos
A ponte entre a necessidade do cliente e a solução técnica através da Engenharia de Software.
* **Práticas:** Técnicas de elicitação de requisitos, escrita de Requisitos Funcionais (RF) e Não Funcionais (RNF), criação de Documentos de Visão e diagramas de Casos de Uso (UML).
